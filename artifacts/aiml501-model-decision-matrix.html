Four questions to ask about any model

⚖Size

How much memory and storage does it need?

Parameters and file size in MB. Smaller fits phones and cheap servers.

🎯Accuracy

How often is it right on a standard test?

Measured on SST-2 and UCI Adult; published ImageNet top-1 for vision.

⏱Speed

How long does one prediction take?

Median CPU latency for one input, after warm-up, on the test laptop.

🔍Explainability

Can we show why it made a choice?

Tree models give exact feature credit; deep nets need add-on tools; chat models are hardest.

Set what matters most for your project. The fit score multiplies each rating by your weight, then ranks models inside each domain. Models from different domains solve different problems, so they are never ranked against each other.

How to choose: a quick path

Start with your data

The type of data picks the family. Your limits on device, accuracy, and explanation pick the model.

Text

Many tasks, no labeled data?Small chat model (Qwen2.5-0.5B) or a cloud chat model
One task with labels, need speed?DistilBERT
One task, best accuracy on a server?BERT-base

Images

Phone or edge device?MobileNetV2
Best accuracy per MB, with a GPU?EfficientNet-B0
Server CPU, mature tools?ResNet-50

Tables

Default choice, must explain?LightGBM or XGBoost + SHAP
Very small dataset, no time to tune?TabPFN (pretrained)
Quick, robust baseline?Random Forest

What the measurements taught me

Method. Speed: median of 30 runs after 5 warm-up runs, one input at a time, CPU only, 4 threads, on a MacBook Air (M4, 16 GB). Language accuracy: all 872 SST-2 validation sentences. Tabular accuracy: UCI Adult, 5,000 training and 5,000 test rows, default settings, seed 42. Vision accuracy: published ImageNet top-1 for the official PyTorch weights. TabPFN could not be run locally because its weights now require an account and license step, so its row uses published results. Code and raw results are in the accompanying document.
